# zynq-thermal-vision-pipeline

**Platform**: Xilinx Zynq-7000 SoC (PL-only pipeline) + Custom Carrier PCB  
**Sensor**: DALI ZE1920NT (MIPI CSI-2, 4-Lane D-PHY, RAW14, 1920x1080 @ 50 FPS)  
**Transport**: HDMI TMDS -> MacroSilicon MS2130 (USB 3.0 Raw Pass-through)  
**Host Stack**: C/C++, `libhsdaoh`, `libusb-1.0`

## Описание проекта

Аппаратно-программный тракт захвата и потокового сжатия без потерь (Lossless) 14-битных радиометрических данных с неохлаждаемого микроболометра DALI ZE1920NT. 

Штатный видеопроцессор камеры (Rockchip RV1126) сжимает поток кодеками H.264/H.265 со снижением частоты кадров до 25 Гц, что из-за нелинейного квантования и DCT разрушает калибровку АЦП. Прямая передача выровненного 16-битного потока (1920x1080 @ 50 Гц) требует полосы 1658.88 Мбит/с (207.36 МБ/с, или до 240 МБ/с с учетом гасящих интервалов видеокадра), что превышает реальную пропускную способность мостов прямого захвата HDMI-to-USB 3.0 (~175 МБ/с).

Проект решает задачу за счет перехвата сырого интерфейса MIPI CSI-2 в ПЛИС, сжатия потока на лету алгоритмом 1D DPCM + Голомб-Райс ($k=2$) до 77–91 МБ/с и его упаковки в стандартный TMDS-кадр для побитовой передачи на ПК через мост MS2130 в режиме `hsdaoh` (с отключенным ISP и JPEG-сжатием).

## Архитектура тракта данных (Data Path)

<img src="docs/Структурная схема.svg" width="750"/>

Обработка полностью реализована в программируемой логике (PL) без участия ядер ARM Cortex-A9, внешней памяти DDR и ОС Linux:

1. **MIPI CSI-2 RX Subsystem**: Десериализация 4 линий D-PHY (148.5 МГц), формирование шины AXI4-Stream (RAW14).
2. **Data Formatter**: Комбинаторное выравнивание RAW14 до 16 бит (RAW16).
3. **Async FIFO (CDC)**: Перенос потока из тактового домена сенсора (148.5 МГц) в домен системной логики и генератора таймингов HDMI. Реализован на базе Dual-Port BRAM с синхронизацией указателей кодом Грея.
4. **Lossless Compressor**:
   * **1D DPCM**: Вычисление межкадровой горизонтальной разности $\Delta_i = P_i - P_{i-1}$ (задержка 1 такт, 0 блоков BRAM и DSP48E1). Первый пиксель каждой строки передается как опорный.
   * **ZigZag & Golomb-Rice (k=2)**: Знаковое отображение $N = (\Delta_i \ll 1) \oplus (\Delta_i \ggg 15)$ и кодирование переменной длины.
5. **Bit Packer & Packetizer**: Упаковка кодов переменной длины в 16-битные слова, добавление заголовка с размером сжатого блока, счетчика кадров и контрольной суммы CRC16 в активную область кадра 1080p.
6. **HDMI TX -> MS2130 -> Host PC**: Сериализация в TMDS и захват на стороне ПК через `libhsdaoh` (DMA в ОЗУ в обход системных драйверов V4L2/DirectShow) с последующим программным декодированием в массив `uint16_t`.

## Основные параметры

| Параметр | Значение |
| :--- | :--- |
| Разрешение и частота | 1920x1080 @ 50 Гц (PCLK = 148.5 МГц) |
| Разрядность данных | 14 бит (RAW14), выравнивание до 16 бит |
| Энтропия Шеннона (выборка 2648 кадров) | Исходный RAW: 1.672 бит/пикс; после 1D DPCM: 0.499 бит/пикс |
| Коэффициент сжатия (CR) | 2.2:1 – 3.5:1 (поток на выходе: 620–730 Мбит/с) |
| Радиометрическая погрешность | 0.00 °C (восстановление бит-в-бит) |
| Задержка вычислителя в ПЛИС | 1 такт (без строчных буферов BRAM) |

## Структура репозитория

Бинарные файлы, сгенерированные IP и временные проекты САПР Vivado (`.xpr`) исключены из Git. Сборка проекта выполняется из TCL-скриптов и Makefile.

```text
zynq-thermal-vision-pipeline/
├── docs/                   # Документация, спецификации и графики моделирования
│   ├── datasheets/         
│   ├── architecture/       
│   └── synth_reports/      # Отчеты утилизации ресурсов (LUT, FF, BRAM) и стат. тайминга
├── pcb/                    # Схемотехника и трассировка несущей платы под SoM
├── hw/                     # Аппаратная часть (SystemVerilog / Vivado)
│   ├── rtl/                
│   │   ├── mipi_formatter/ # Прием MIPI CSI-2 и расширение RAW14 -> RAW16
│   │   ├── cdc_fifo/       # Асинхронный FIFO с указателями в коде Грея
│   │   ├── compressor/     # Модули 1D DPCM, ZigZag и кодера Голомба-Райса
│   │   └── hdmi_packer/    # Bit Packer, расчет CRC16 и упаковка в HDMI-кадр
│   ├── tb/                 # Тестбенчи для побитовой верификации
│   ├── constraints/        # XDC-ограничения пинов и тактовых частот (148.5 MHz)
│   └── bd/                 # TCL-скрипт генерации Block Design
├── sw/                     # ПО приемной части на ПК
│   ├── capture/            # Прием потока с MS2130 через libhsdaoh / libusb
│   ├── decoder/            # Проверка CRC16, декодер Голомба-Райса и 1D DPCM
│   └── scripts/            # Python-скрипты анализа энтропии и верификации кадров
├── scripts/                
│   ├── build_hw.tcl        # Скрипт автоматической генерации проекта Vivado и битстрима
│   └── Makefile            
└── README.md
